# Contributing

1. Fork this repository and create a feature branch: `git checkout -b feat/my-feature`
2. Build and test: `./gradlew assembleDebug`, then install the APK on a device or emulator.
3. Commit with a clear message, push, and open a Pull Request.

For bug reports, open an Issue and attach `latestcrash.txt` from the launcher data folder
if the app crashed.
