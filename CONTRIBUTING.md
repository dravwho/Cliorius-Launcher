# Berkontribusi

1. Fork repo ini, buat branch fitur: `git checkout -b feat/nama-fitur`
2. Build & uji: `./gradlew assembleDebug`, lalu tes APK di HP/emulator
3. Commit dengan pesan jelas, push, lalu buat Pull Request

Laporan bug: buka Issue dengan isi `latestcrash.txt` (dari folder data launcher) bila crash.
